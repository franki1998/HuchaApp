# Hucha en dos minutos

## El problema

Organizar el dinero de un plan en grupo suele acabar en una hoja de cálculo, un hilo de
mensajes y alguien persiguiendo a los demás para cobrar. Las apps existentes ayudan a
calcular deudas **después** de gastar, pero no ayudan a acordar **antes** cuánto pone cada
uno ni a ver cuánto queda.

## La idea

Una **hucha** es un plan con un presupuesto compartido:

- Cada participante compromete una cantidad.
- Cada gasto consume parte de lo comprometido por quienes participan en él.
- Todo el mundo ve lo mismo: comprometido, utilizado, restante.

## Para quién

Viajes con amigos · parejas · pisos compartidos · cumpleaños y eventos · cualquier grupo
que comparte gastos durante un tiempo.

## Cómo se usa (un minuto)

Registrarse con el teléfono → crear una hucha → compartir el enlace → cada uno dice
cuánto pone → añadir el primer gasto.

## Lo que Hucha no es

- No es un banco ni custodia dinero.
- No pide credenciales bancarias.
- No está pensada para contabilidad profesional.
